# Learning proposal: Reuse prepared Web SFX sources when URL changes retain native audio nodes

Status: proposed; human review and merge required.

## Observed problem

Pinned audioplayers_web changes source URL on shared voices, recreating native media nodes retained by Blink after release during repeated UI navigation.

## Proposed improvement

Add conditional Sound guidance to inspect strong retained native paths and reuse finite prepared channel/asset sources when backend recreation is measured, preserving a three-active-voice cap and complete disposal.

    # Web SFX source retention — observed and verified

    Flutter 3.27, audioplayers_web 5.2.0 and Chrome 153, using the same real Settings/Back touch workload. Ten warm cycles followed by thirty cycles, forced GC at each ten-cycle sample; profile builds preserve class names. No app state injection.

    Before: `route-memory-profile-2/object-counts.json`, `analysis.json`, and `strong-retainers.json` show MediaElementAudioSourceNode 20 → 80 and DOM nodes 104 → 224. GameButton and route counts stay fixed. The strong root path runs through Blink PendingActivities, not a guessed Dart owner. Installed wrapped_player.dart recreates media element/source when a voice changes URL.

    After: `route-memory-fixed-profile/object-counts.json`, `analysis.json`, and `retaining-paths.json` show sources 3 → 3 and DOM nodes 68 → 68. lib/audio/audio_adapters.dart prepares each finite (channel, asset) source once and resumes it, stopping the previous source on that channel. At most three sources play concurrently; the finite pool may contain more prepared sources than active voices. All owned players are disposed.

    Regression tests alternate eighty UI events and replay the complete finite sound set, proving preparation is bounded, active voices do not exceed three, and disposal stops/releases the entire pool. Full suite: 112 passed at this checkpoint. No music was added and no package/SDK versions were changed.

    Limit: this is a backend-specific measured remedy, not a claim that every audio package leaks or that a source pool of three is sufficient for every finite sound catalog. Residual input object growth was separately diagnosed and is not hidden by the DOM result.
