# /store-screenshots checklist

Read this after a compaction instead of `SKILL.md`; open a `SKILL.md` section by its heading only
when a step is unclear. The panorama is the approved concept and is never re-rendered; the
banner, icon and emblem each have a correction budget; the kit ships one ZIP that passes
`check_store_kit.py`.

| Phase | Do | Exit |
|-------|----|------|
| 0 preflight | pick `STORE_PYTHON` (Pillow + numpy); `PROJECT_NAME`, `TS`, `STORE_DIR=project_zip/$PROJECT_NAME-store-$TS`, `ART_DIR`, `RAW_DIR`, `OUT_DIR`, `PLAY_DIR`; `python3 tools/concept_gate.py status` → APPROVED: copy `production/store-art/concept/panorama.png` byte-identical, read `export-flags.txt` and `gameplay-sample.md`; PENDING/DRAFTING → BLOCKED; NONE → concept-panorama.md (legacy); copy `shared-background.png` (not with `--keep-runtime-background`); a banner valid for this panorama → copy; `STORE_BRIEF.md`; background guard (runtime-branding.md); a current context capture if none (`web_verify.mjs --size 390x844 --budget 150 --quick`) | brief written; inputs in `$ART_DIR` |
| 1b banner | reuse first (campaign-art.md Step 4); else `store_compose.py banner-guide --canvas 3840x1872 --lead … --field … --ball … --object … --out production/store-art/banner-guide.png` (`--canvas 1536x1024` built-in); render `banner-character|object` from campaign-prompts.md + `prompt_template.py check`; ONE call: character asset, panorama, guide, multiplier reference, capture, sprites; `art_lineage.py record --role banner --made fresh …`; review with `banner-guide --over <candidate>` and the 1024×500 crop | passes, or budget spent (3 fresh / 5 repairs; never the same method twice on one defect) |
| 2 review | one contact sheet of the final App Store + Play crops + the feature graphic; objective checks only — `x5 x10 x25 x50 x100` once each, a ball in every panel, ≥ 2 over gameplay, none on the player, torso-to-head, no pasted boundary, the panorama's crops not its art; correction policy (crop → region repair → fresh render); no re-audit of unchanged art | PASS |
| 3 branding + captures | reuse finalization's icon and emblem (`python3 tools/art_lineage.py verify --file assets/branding/app_icon.png`, same for `assets/images/ui/ui_game_logo.png`); generate and apply only what is missing (runtime-branding.md), and touch Dart/pubspec only then; captures: menu, active play, peak, win, meta via `web_verify.mjs --size 390x844 --dpr 3 --budget 180 --quick` on the campaign background | current authentic frames in `$RAW_DIR` |
| 4 exports | `FLAGS=$(cat production/store-art/concept/export-flags.txt)`; `triptych --src "$ART_DIR/panorama.png" --out "$PLAY_DIR" --size play $FLAGS` and `--out "$OUT_DIR" --size 1320x2868 $FLAGS`; a ~1.6 MP source gets the detail pass first (`region_repair.py upscale --height 2868`, ≤ 4 `merge --mode detail` windows, `--made derive|detail --parent …`) | both sets from the same source |
| 5 showcases + feature | `showcase --shot "$RAW_DIR/…" --bg "$ART_DIR/shared-background.png" --out … --size 1320x2868 --caption … --type-mood … --pop soft` per capture slide (Play separately); `banner --keyart "$ART_DIR/long-banner.png" --out "$STORE_DIR/feature-graphic-1024x500.png" --base-out … --size 1024x500 --pop soft --lead-kind … --banner-layout free --banner-gate off --shot <active capture> --frame android` | N App Store + N Play + feature graphic |
| 6 verify + package | `store_compose.py check --dir "$OUT_DIR" --store appstore` (+ Play); no-gambling copy check; background guard `cmp` UNCHANGED; `STORE_INFO.md`; `branding/app_icon.png`, `store_icon_512.png`, `emblem.png`; `cp production/store-art/lineage.json "$ART_DIR/lineage.json"` + `art_lineage.py --ledger "$ART_DIR/lineage.json" verify --file …` for every shipped picture; `STORE_DELIVERY.json` (PASS only from the real review); `zip -r`, `unzip -t`, `shasum`; `check_store_kit.py --archive … --count "$STORE_COUNT" --concept production/store-art/concept/concept.json` | gate passes; ZIP path reported |

Read `SKILL.md` once and the references it names when their step comes (campaign-handoff.md in
preflight, campaign-art.md Step 4 for the banner, runtime-branding.md only if branding is
missing); after a compaction come back here. Evidence of failed attempts goes under
`production/store-art/failed-delivery/`.
