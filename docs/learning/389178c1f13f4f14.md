# Learning proposal: Scope component motion assertions inside route hosts

Status: proposed; human review and merge required.

## Observed problem

A result-star test matched unrelated MaterialApp transition transforms and reported a false failure although the three star transforms had settled.

## Proposed improvement

Add bounded test guidance to scope component animation finders to the component subtree and assert the expected node count before checking motion.

Base commit: `0ba1407524f72af534c05e569f42d6afdd1d3bde`
