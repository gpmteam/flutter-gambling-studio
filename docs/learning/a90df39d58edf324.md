# Learning proposal: Hydrate missing dependency metadata before resumed Flutter checks

Status: proposed; human review and merge required.

## Observed problem

Resume analyzed a relocated Flutter project without package_config metadata, producing 1226 unresolved import cascade issues despite unchanged previously clean source.

## Proposed improvement

Use the existing locked dependency hydration guidance before resumed analyzer/test gates when generated package metadata is missing; preserve source and report hydration failures precisely.
